# 评价聚合框架过程报告

## 已实现

- 逐样本指标 JSONL 的 sample_id 唯一性、正式集合归属、指标字段一致性和有限值检查；
- 默认要求正式 split 100% 覆盖，缺样本立即失败；仅调试时可显式允许不完整；
- Overall、Consistent/Conflict、官方七类情感、七类×二类四种聚合层级；
- 固定随机种子的非参数 bootstrap 95% 置信区间；
- 同时输出 JSON 与 CSV，不自动生成或虚填论文表格。

## 边界

本步骤只实现严格聚合层。EGA、VQ-a、CUA、DCA 等指标的逐样本计算必须按论文定义另行实现并核验后，才能输入本工具；当前合成测试值不能用于论文。

服务器合成回归测试已通过：完整覆盖、样本数、指标名、overall 分组数量和置信区间顺序均正确。
