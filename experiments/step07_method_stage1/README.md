# SpchConvSti 方法实现框架

本目录以论文方法为唯一设计来源。当前已实现模块一的公式级核心，以及模块二、模块三可独立验证的数学核心。旧项目代码不作为实现依据。

## 当前范围

- 正式版本 B JSONL 数据读取与校验。
- 语音、文本、OpenSMILE 韵律和对话上下文的张量契约。
- 双向 InfoNCE、Whisper 词级时间窗对齐、全局/局部冲突向量。
- 上下文语义补全、维度级情感仲裁与联合情感—语义表示。
- 双流条件投影、K 项风格码本和 CA-FM。
- 潜空间三维奖励与 Constant-Noise DDIM 轨迹修正。
- 前向、损失和反向传播冒烟测试。

Whisper、WavLM、OpenSMILE 和 Stable Diffusion 的真实模型接入不在本次冒烟测试中下载；接口使用预提取特征，避免在语音尚未完成时占用 GPU 0。
