# 方法公式实现过程报告

## 原则

本轮以用户提供的论文正文为唯一方法依据，旧代码不作为结构来源。未下载服务器音频，未占用 GPU 0，未启动正式训练。

## 关键纠正

此前临时骨架使用软注意力对齐，并把数据集的 Conflict/Consistent 标签作为冲突分类 BCE。重新核对正文后已删除该做法。正式模块一按照 Whisper 时间戳进行词级均值对齐，训练损失采用正文定义的双向 InfoNCE。数据集二分类标签保留用于数据分层、分组评测和后续分析，不被擅自加入正文未定义的分类损失。

## 实现顺序

1. 建立 RoBERTa、WavLM、OpenSMILE、Whisper 与上下文的张量契约。
2. 实现韵律增强语音适配器及双向 InfoNCE。
3. 实现词级时间窗对齐、全局和局部冲突向量。
4. 实现上下文 cross-attention、仲裁向量和联合 Transformer 表示。
5. 实现双流投影、VQ 风格码本、L_code 与 CA-FM。
6. 实现 Tweedie 估计、三维奖励、动态权重、Constant-Noise 与 DDIM 修正。
7. 在 CPU 上执行形状、mask、公式性质、损失和梯度测试。

## 需要用户知情但暂不要求修改正文的实现细节

1. 正文写“拼接三个向量后输入多层 Transformer”，但没有定义 Transformer 的序列维。代码采用一个拼接融合种子 token，加语义、语音、冲突三个组件 token，再取融合 token 作为 h_joint。若正文后续补充更明确的序列构造，需要同步调整代码。
2. 正文只写 alpha 由轻量 MLP 产生，没有写激活函数。代码使用 Sigmoid，使维度级仲裁系数位于 [0,1]。这属于实现超参数，当前无需修改正文，但最终实验设置应记录。
3. CA-FM 的四组预测/投影层采用零初始化，使接入预训练 U-Net 时初始行为为恒等映射，降低破坏预训练分布的风险。正文没有规定初始化方式，最终实验设置应记录。
4. 正文一处表示对齐训练完成后移除投影头，同时联合训练目标仍包含 L_align。代码解释为：训练期间保留投影头以计算 L_align，仅推理时移除或绕过。若作者原意不同，需要修改正文或训练方案。
5. 正文中的 lambda_1 控制总损失里的 L_code，而 L_code 内部又使用 lambda_code 控制 commitment 项。代码分别称为外层 `lambda_code` 和量化器 `commitment_weight`，避免同名混淆。
