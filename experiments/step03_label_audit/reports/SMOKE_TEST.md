# 步骤03冒烟测试报告

## 测试目的

验证本地视觉语言模型能否稳定读取实际表情包图像、输出七分类标签，并在完全不读取表情包信息的情况下独立输出当前话语的三分类情感极性。本测试只用于验证流程和筛查标签噪声，不直接修改任何官方标签。

## 测试配置

- 模型：`gemma3:12b`
- 运行环境：Ollama 0.32.7，0号 RTX 3090
- 样本：14条，每个 `origin_anno` 类别2条
- 推理参数：`temperature=0`，`seed=20260810`
- 图片任务输出：Happiness、Sadness、Anger、Surprise、Disgust、Fear、Neutral 七分类
- 文本任务输出：Positive、Negative、Neutral 三分类
- 信息隔离：图片任务不向模型提供 `origin_anno`；文本任务不提供图片、表情包标签或表情包描述

## 执行结果

- 第一轮：14/14成功，无 JSON 解析错误。
- 第二轮：14/14成功，无 JSON 解析错误。
- 图片分类结果的跨两次运行稳定率：14/14（100%），即同一张图片重复推理两次得到相同类别。
- 文本极性结果的跨两次运行稳定率：14/14（100%），即同一句文本重复推理两次得到相同极性。
- 上述稳定率只衡量模型重复运行是否稳定，不衡量文本情感与图片情感是否一致。
- 首轮模型与官方 `origin_anno` 一致：6/14（42.86%）。
- 首轮文本极性分布：Positive 8条、Neutral 5条、Negative 1条。

## 质量判断

1. 工程流程通过：图像路径、实际图片输入、结构化输出、样本对应关系和断点续跑均正常。
2. 在固定参数下，模型输出具有完全可重复性，但可重复不等于标签一定正确。
3. 14条中仅6条与官方标签一致，说明 `origin_anno` 的潜在噪声值得系统核验；样本量很小，不能据此估计整个数据集的真实错标率。
4. 模型置信度暂不能作为自动改标依据。例如，有一条输出的文字证据明确称图像较含糊，但结构化字段仍给出 `ambiguous=false`。这表明模型自报置信度和歧义字段存在校准问题。
5. 单个模型不能成为最终标签修正者。Gemma 3 12B 的结果只用于生成错标候选，候选至少还需另一个视觉模型独立复核；存在分歧的样本继续保留官方标签或进入单独审查队列。

## 下一步

- 引入第二个视觉模型，对 Gemma 与 `origin_anno` 不一致的样本进行盲审复核。
- 在复核规则冻结前，不写入 `corrected_label`，不计算正式的冲突/一致标签分布，也不修改论文表格。
