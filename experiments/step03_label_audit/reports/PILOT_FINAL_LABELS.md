# 208条小试验最终派生标签报告

## 已冻结的规则

### 表情包标签

- 继续使用 STICKERCONV 官方字段 `origin_anno`。
- 不修改、不覆盖官方七类标签。
- Gemma 与 Qwen3-VL 的图片判断只保留为 `sticker_review_status` 和候选信息，用于质量审计与案例分析，不参与替换官方标签。

### 七类标签到极性的映射

| 七类表情包标签 | 极性 |
|---|---|
| Happiness | Positive |
| Surprise | Positive |
| Sadness | Negative |
| Anger | Negative |
| Disgust | Negative |
| Fear | Negative |
| Neutral | Neutral |

### 当前文本极性

1. Gemma 与 Qwen3-VL 文本极性一致时，直接使用一致结果。
2. 两者不一致时，使用独立的 Qwen3 8B 文本模型盲审裁决；该模型不读取表情包、官方标签或前两模型标签。

### 二分类冲突规则

仅当文本极性与官方表情包极性构成“Positive—Negative”或“Negative—Positive”时，标记为 `Conflict`；所有其余组合均标记为 `Consistent`。最终不存在第三类标签。

## 208条小试验结果

| 项目 | 数量 |
|---|---:|
| 样本总数 | 208 |
| Conflict | 62 |
| Consistent | 146 |
| 文本双模型直接一致 | 159 |
| 文本分歧并由 Qwen3 裁决 | 49 |

第三模型在49条分歧中与 Gemma 标签一致21条、与 Qwen3-VL 标签一致25条；其余样本形成三模型不同的情况。这说明文本情感本身存在一定主观性，因此本数据集采用上述固定、可复现的裁决链，而不声称其为人工金标准。

## 可追溯性

- 每条记录保留官方 `origin_anno`、三方图片候选、文本极性来源和最终二分类标签。
- `sticker_review_status` 记录三方一致、双模型候选或模型分歧状态。
- 原始数据、官方标签和模型原始输出均未被覆盖。

## 适用范围

本报告的62/146比例来自按七类情感近似均衡抽取的208条小试验，不能写入论文作为全数据集比例，也不能用于正式表格。它仅证明规则、模型调用、断点续跑和审计记录流程可执行。下一步需将同一规则应用到官方训练、验证和测试划分，之后再进行正式数据集分析。
