# 步骤03类别均衡小样本筛查报告

## 目的与范围

本轮使用 Gemma 3 12B 对208条类别均衡样本进行盲审筛查，目的在于估计不同官方类别中的潜在标签噪声，并验证文本情感极性推断流程。该样本不是从真实分布随机抽取，因此不能据此推断整个数据集的总体错标率、情感分布或冲突比例。本轮没有修改任何 `origin_anno`。

## 数据组成

- Happiness、Sadness、Anger、Surprise、Fear、Neutral：各30条。
- Disgust：任务目标中共28条，全部纳入。
- 合计：208条。

## 执行状态

- 成功：208条。
- 失败：0条。
- 平均耗时：11.75秒/条。
- 中位耗时：11.77秒/条。
- Gemma 图片分类与官方标签一致：109/208（52.40%）。
- Gemma 图片分类与官方标签不一致：99/208（47.60%）。

上述文本极性是模型输出的小样本筛查结果，尚未经过第二模型复核，也尚未与修正后的表情包类别组合生成正式的“冲突/一致”标签。

## 主要风险

1. Gemma 对208条图片全部报告 `ambiguous=false`，图片分类平均自报置信度为0.969，说明其置信度和歧义字段明显过度乐观，不能作为自动改标阈值。
2. Fear、Disgust、Neutral 的模型—官方分歧尤其大，既可能来自官方标签噪声，也可能来自表情包的夸张、幽默、讽刺和混合情绪，还可能包含模型分类偏差。
3. 208条按官方类别近似均衡，不能把52.40%直接写成全数据集标签准确率或错标率。
4. 单一模型无权修改官方标签。99条不一致样本当前只标记为疑似错标候选。

## 决策与下一步

- 引入独立的 Qwen3-VL 8B，对相同图片进行盲审复核。
- 先在每类2条的14条样本上验证 Qwen 的结构化输出和重复稳定性。
- Qwen 验收通过后再处理208条，以获得“官方标签—Gemma—Qwen”三方关系。
- 只有当两个独立视觉模型对同一图片给出相同类别、且共同反对 `origin_anno` 时，才将其列为高优先级修正候选；该条件仍不等于自动覆盖官方标签。
- 在表情包标签修正规则和文本极性复核规则冻结前，不生成正式冲突标签，不修改论文表格。
