# Qwen3-VL 独立复核模型冒烟测试报告

## 目的

验证 Qwen3-VL 8B 能否作为独立于 Gemma 3 12B 的第二视觉模型，对表情包七分类和文本三极性进行盲审复核。本测试仍不修改任何官方标签。

## 环境与兼容性处理

- 模型：`qwen3-vl:8b`
- 模型大小：6.1GB
- 运行环境：Ollama 0.32.7，0号 RTX 3090
- 初次测试发现模型将结构化 JSON 写入 `message.thinking`，而 `message.content` 为空。
- 脚本已调整为优先解析 `content`，为空时回退解析 `thinking`，并记录实际响应字段。
- 分类任务显式关闭思考模式并将最大输出限制为256个 token，以避免不必要的长推理。

## 测试结果

- 两轮各14条，共28次推理，全部成功。
- 图片分类结果的跨两次运行稳定率：14/14（100%）。
- 文本极性结果的跨两次运行稳定率：14/14（100%）。
- Qwen 图片分类与官方标签一致：7/14。
- Qwen 图片分类与 Gemma 图片分类一致：10/14。
- Gemma 与 Qwen 共同给出相同非官方类别：5/14。
- Qwen 与 Gemma 的文本极性一致：12/14。

## 判断

1. Qwen3-VL 8B 的工程流程和重复稳定性通过验收，可以进入208条独立复核。
2. 两个模型存在分歧，说明不能把任一单模型视为绝对真值。
3. 两个模型共同反对官方标签时，可将样本列为高优先级疑似错标候选，但不能仅凭该条件自动覆盖 `origin_anno`。
4. 文本极性也需要比较双模型结果；模型一致的样本可信度较高，模型不一致的样本应进入待裁决队列。

## 下一步

- 统计官方标签、Gemma、Qwen 的三方一致关系。

- 根据三方结果制定明确、可复现的标签保留、修正候选和待裁决规则。
