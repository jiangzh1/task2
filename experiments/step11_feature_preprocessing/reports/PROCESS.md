# 图像侧预处理过程报告

## 当前任务

在不等待语音的情况下，建立正式版本 B 的 sample→目标 sticker 映射，执行图片解码、尺寸、模式、SHA-256 和字节级跨划分泄漏检查，并准备 SD1.5 VAE latent 的断点缓存入口。

## VAE 预处理暂定策略

- RGBA 先合成到白色背景并转 RGB；
- 默认等比例缩放并白边补齐到 512×512，不裁掉 sticker 内容；
- 使用 VAE posterior mode 形成确定性缓存；
- 使用 SD1.5 标准 latent scale 0.18215；
- 每张图按 SHA-256 命名并原子写入，已有文件直接跳过。

这是工程预处理选择，论文正文目前没有规定 resize/background/mode。正式训练前需把这些设置写入实验设置，但本轮不修改论文。

## 图像完整性与泄漏审计结果

- 3,554 个目标表情包路径全部存在且可由 PIL 解码；
- 共得到 3,465 个唯一 SHA-256；
- 存在 76 个“多路径但字节相同”的哈希组；
- 旧路径分组划分中有 33 个相同图像哈希组跨集合，属于真实的目标图像泄漏风险。

因此 VAE latent 缓存没有在旧划分上启动。数据改为按 SHA-256 分组重划分后，新 manifest 再次验证 12,930 样本、3,554 路径全部有效，图像哈希跨集合为 0。SD1.5 权重完成后，在 GPU 1 完成 hash-safe VAE latent 缓存：3,465 个唯一哈希全部成功，89 个重复路径在命中同一哈希文件后跳过，失败 0。独立复核确认 3,465 文件均为 `[4,64,64]`、数值有限、SHA 文件名和预处理元数据正确。输出目录为 `artifacts/vae_latents_hashsafe/`，占用约 123 MB。详细修复见 `step04_full_dataset/reports/HASH_SAFE_RESPLIT.md`。
