# 情感语音生成：完整交接报告与生产版本 1

更新日期：2026-09-21  
适用项目：表情包情感多模态数据集的英文语音生成

## 1. 当前最终决定

生产版本 1 使用 `CosyVoice-300M-Instruct`、内置说话人 `英文女`、`inference_instruct`。

| 情感 | 生产 v1 提示词 | 来源/决定 |
|---|---|---|
| Happiness | `Happy: bright, warm, lively, light rhythm.` | 冻结 v1 保留。 |
| Sadness | `Sad: subdued, slow, heavy, low.` | 人工试听优于真人参考。 |
| Anger | `Angry, indignant, controlled; emphatic key words, varied pace, falling stress.` | v10；用户最终决定先采用；v1 同时保留。 |
| Surprise | `Surprised: startled, high-pitched, animated.` | 冻结 v1；新版无稳定收益。 |
| Disgust | `Disgusted but controlled: clear aversion and recoil, clipped phrase groups, brief tense pauses, slight scoffing downward inflection on emphasized words. Never happy or angry.` | v9/v2；用户试听选择。 |
| Fear | `Fearful: panicked, breathless, trembling, urgent.` | 冻结 v1；新版过快、缺乏脆弱感。 |
| Neutral | `Neutral: matter-of-fact, even, natural.` | 冻结 v1；新版起伏过多。 |

固定数据规则：只合成表情包/图像前紧邻的完整 `user` 文本；不能合成整个对话、assistant 文本或控制提示词。音频需峰值归一化至 0.95、Whisper-base WER ≤ 0.20、无重复 5-gram。

## 2. 正式生成策略

每条文本首次只生成一次。首次音频通过文本一致性校验（Whisper-base WER ≤ 0.20、无重复 5-gram）后立即作为最终结果，不再生成第二、第三次。只有文本一致性失败时才重试，最多共 3 次；三次均失败则记录为失败，不无限重试。恢复任务时跳过已完成合格项。

情感识别器用于离线评测、抽检和定位问题；除下述 Other/UNK 例外以外，它不触发额外生成，也不会因“非 Other 的分类不正确”替换已通过内容门槛的音频。这样避免三倍成本，也避免按识别器偏好扭曲数据分布。

**Other/UNK 例外规则：**每次通过内容门槛后执行情感识别。若原始标签不是 Other/UNK，直接定稿；若是 Other/UNK，则查看七个正式类别中的最高分：最高分 `> 0.30` 时，将该条标记为该最高分类别并定稿；否则才重试。最多 3 次后仍为 Other/UNK 且没有类别超过 0.30，则保留为 Other 并进入失败/人工复核清单。该规则来自 v7，现作为生产 v1 的唯一情感驱动重试规则。

## 4. 已记录的人类试听判断

- Sadness：提示词版更有 down、难过、叹气感；真人参考过平，只是慢。
- Anger：需要愤慨、重点重音、强弱和速度变化；最终 v10 在部分未见文本更好。
- Happiness：略不够欢快，但数值足够时不优先调整。
- Surprise：与 Happiness 难分；“wow”感难稳定强化。
- Disgust：新版优于旧版，但目前是凶/排斥多于鄙视/讽刺。
- Fear：需要克制、脆弱、紧张；v9 过快，回退 v1。
- Neutral：必须平淡、少重音和少起伏；v9 失败，回退 v1。

## 5. 当前已知问题与后续优化条件

1. 语义积极或中性的文本可能压过目标表情标签，导致 Anger/Fear/Disgust 被判为 Happiness 或 Neutral。
2. Fear 没有稳定解决方案；若数千条规模抽检不合格，优先重启真人参考与短提示词 A/B，而不是继续加长 prompt。
3. Disgust 缺乏讽刺/鄙视细节；若规模抽检不合格，测试一条更短的 cold rejection 候选，避免复杂指令。
4. Anger v10 与 v1 均有文本依赖；规模评测若 v10 明显差，可立即回退到 v1 的短提示词。

## 6. 清理后的唯一保留资产

| 保留项 | 用途 |
|---|---|
| `production_v1/docs/本报告` | 所有提示词、历史、结果、回退方法。 |
| `production_v1/prompt_audio/frozen_v1/` | 原七类冻结控制音频，含 Anger v1 回退依据。 |
| `production_v1/prompt_audio/frozen_v2/` | Disgust v2 音频。 |
| `production_v1/prompt_audio/anger_v10_final/` | Anger v10 最终 A/B 音频与未见文本报告。 |
| `production_v1/reference_audio/` | 每类最新有效真人参考样本；旧真人测试目录不保留。 |
| `production_v1/code/` | 最新可复现的提示词与真人参考生成脚本、内容门槛与评测脚本。 |

其中 `production_v1/code/production_v1_config.json` 是唯一的生产提示词配置；`generate_production_v1.py` 读取该配置、从每个官方 JSONL 记录中反向取得最后一条非空 `user` 文本，并实现“三次内容门槛/Other-UNK 例外”断点续跑规则。要回退某一类，只需在此 JSON 将该类字段替换为第 3 节明确记录的历史提示词，而不需要恢复已删除的旧脚本。

所有其它历史音频、重试候选、冒烟测试、过时评测日志、旧脚本均可删除；回退提示词依赖本报告，不依赖旧文件。

## 7. 执行顺序

1. 使用生产 v1 生成数千条；记录逐条候选、最终选择、失败原因。
2. 分层随机抽检并计算七类准确率、混淆矩阵、Other 率；人工只评价情感正确性。
3. 若结果可接受，冻结生产 v1；若不合格，依据第 5 节从 Fear、Disgust、Anger 的指定路径继续。
